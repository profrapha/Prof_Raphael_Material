## Estrutura de Pastas

Este repositório está organizado para facilitar a criação e o controle de versão dos materiais em LaTeX. A organização interna de cada turma é separada por Unidade e Tema.

- `/Scripts_e_Protocolos`: Scripts em Python e protocolos gerais de elaboração de exercícios.
- `/Modelos_Templates`: Arquivos base (`.tex`) configurados com o cabeçalho e pacotes padrão da escola.
- `/Matematica_Algebra`: Diretório principal agrupando o Ensino Fundamental II e Ensino Médio.
  - `/6_Ano`
  - `/7_Ano`
  - `/8_Ano`
    - `/Unidade_01_Polinomios` *(exemplo de subpasta por tema)*
  - `/9_Ano`
  - `/1_Serie`
    - `/Unidade_01_Funcoes` *(exemplo de subpasta por tema)*
  - `/2_Serie`
  - `/3_Serie`

*Nota: Arquivos auxiliares de compilação do LaTeX estão configurados para serem ignorados pelo controle de versão via `.gitignore`.*
